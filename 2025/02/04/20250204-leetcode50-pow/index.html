题目

实现 pow(x, n)，即计算 x 的 n 次幂。

解题思路

使用快速幂（分治）：

  • 若 n 为偶数：x^n = (x^(n/2))^2
  • 若 n 为奇数：x^n = x * x^(n-1)

为了处理负指数，把 x 取倒数并将 n 取相反数。

复杂度分析

  • 时间复杂度：O(log n)
  • 空间复杂度：O(1)
