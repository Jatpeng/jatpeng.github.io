1. override 和final 限定符

override ：编译器帮忙检查，用于父子类对父类override函数被实现，避免出现override 函数调用失败

final ：加到父类函数后避免在子函数中被override

加到类名后,类就无法被继承

2.静态成员static

static 变量不依赖任何一个类对象，单独存在。单独初始化

static function：只能访问静态成员。non static 变量依赖类的实例化而存在的，要想访问需要在函数里先创建对象，再访问变量。
