## C++ 左值和右值
左值：可以放在等号左边，可以被修改的值，左值可以是变量，也可以是常量。可以被取地址。
右值：只能放在等号右边，不能被修改的值，右值可以是变量，也可以是常量。不能被取地址。
## 1.实现C++ string 类
https://cloud.tencent.com/developer/article/2456266
```C++
namespace W
{
class String{
public:
    size_t capacity;
    char* _str;
    size_t _size;
    
    //构造函数
    String(const char* str = ""){
        _size = strlen(str);
        capacity = _size;
        _str = new char[_size+1];//多开一个空间，用来存放'\0'
        strcpy_s(_str,_size+1,str);
    }
    
    //拷贝构造函数,深拷贝，两个对象指向不同的内存
    String(const String& s){
        _size = s._size;
        capacity = s.capacity;
        _str = new char[capacity+1];
        strcpy_s(_str,capacity+1,s._str);
    }
    
    //移动构造函数
    String(String&& other) noexcept {
        _str = other._str;
        _size = other._size;
        capacity = other.capacity;
        
        // 将源对象置为空状态
        other._str = nullptr;
        other._size = 0;
        other.capacity = 0;
    }

    //拷贝赋值运算符
    String& operator=(const String& s){
        if(this != &s){
            delete[] _str;
            capacity = s.capacity;
            _size = s._size;
            _str = new char[capacity+1];
            strcpy_s(_str,capacity+1,s._str);
        }
        return *this;
    }
    
    //移动赋值运算符
    String& operator=(String&& other) noexcept {
        if(this != &other){
            // 释放当前对象的资源
            delete[] _str;
            
            // 转移资源所有权
            _str = other._str;
            _size = other._size;
            capacity = other.capacity;
            
            // 将源对象置为空状态
            other._str = nullptr;
            other._size = 0;
            other.capacity = 0;
        }
        return *this;
    }
    //赋值运算符返回的是引用，因为可以连续赋值
    //深拷贝，两个对象指向不同的内存，避免浅拷贝的问题

    ~String(){
        delete[] _str;
        _str = nullptr;
        _size = 0;
        capacity = 0;
    }

};
}
```

## 2.移动语义和右值引用

移动语义是C++11引入的重要特性，通过右值引用(&&)实现资源的转移而非复制，显著提升性能。

### 移动构造函数的优势：
1. **避免不必要的内存分配和复制**：直接转移资源所有权
2. **提升性能**：特别是在处理临时对象时
3. **减少内存碎片**：避免频繁的new/delete操作

### 移动赋值运算符的特点：
1. **noexcept声明**：保证不抛出异常，提升容器操作效率
2. **自赋值检查**：防止对象移动给自己
3. **资源清理**：正确释放当前对象资源后再转移

### 使用示例：
```cpp
String createString() {
    return String("Hello World"); // 返回临时对象
}

String s1 = createString(); // 调用移动构造函数
String s2;
s2 = std::move(s1); // 调用移动赋值运算符
```

在游戏开发中，移动语义特别有用于：
- 大型字符串的传递
- 容器元素的重新排列
- 临时对象的优化处理
